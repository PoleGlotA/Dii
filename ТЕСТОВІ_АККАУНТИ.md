## Як увійти

1. Запустіть сайт (`npm run dev`)
2. Натисніть **«Увійти»** на головній сторінці
3. Вставте email з таблиці вище
4. Введіть пароль: `demo1234`

## Створення власного акаунта

Перейдіть на `/auth/register` — реєстрація працює повністю:
- Email-валідація
- Хешування пароля (SHA-256 + salt)
- Перевірка надійності пароля
- Збереження в `localStorage` ключ `dii_state_v3`

## Очищення тестових даних

У DevTools:
```js
localStorage.removeItem("dii_state_v4");
localStorage.removeItem("dii_remember_email");
location.reload();
```

Або у консолі браузера:
```js
Object.keys(localStorage)
  .filter(k => k.startsWith("dii_"))
  .forEach(k => localStorage.removeItem(k));
location.reload();
```

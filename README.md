# Дій — Волонтерська платформа

Гібрид форуму та менеджера подій для волонтерів: події, збори, новини, заявки, обговорення, профіль із кармою.

## Запуск локально

Потрібен Node.js 18+ ([nodejs.org](https://nodejs.org)).

**Windows:** двічі клікнути `Запустити (Windows).bat`
**macOS:** двічі клікнути `Запустити (macOS).command`

Скрипт сам встановить залежності та відкриє [http://localhost:3000](http://localhost:3000).

Або через термінал:

```bash
npm install
npm run dev
```

## Продакшн-збірка

```bash
npm run build
npm start
```

## Деплой

### Vercel (рекомендовано)

1. Створіть акаунт на [vercel.com](https://vercel.com).
2. Завантажте проєкт у GitHub-репозиторій.
3. У Vercel → **Import Project** → виберіть репозиторій → **Deploy**.
4. За хвилину отримаєте домен виду `dii-volunteer.vercel.app`.

### Інші хостинги (Netlify, Railway, Render)
- Build: `npm run build`
- Start: `npm start`
- Node: 18+

## Функціонал

### Користувачі
- Реєстрація з email і паролем
- Вхід з валідацією та помилками
- Швидкий вхід під тестовими акаунтами
- Редагування профілю (ім'я, місто, біо, роль, аватар)
- Розділення ролей: волонтер / організатор

### Контент
- 15 готових публікацій (події, збори, новини)
- Стрічка з фільтрами за типом, містом, сортуванням
- Пошук за заголовком, описом, тегами
- Сторінка деталей з підтримкою Markdown
- Прогрес-бар для зборів + кнопка донату
- Лічильник місць для подій

### Взаємодія
- Заявки на участь зі статусами: очікує / прийнято / відхилено
- Панель організатора: підтвердження/відхилення заявок
- Коментарі під кожним постом
- Створення нових публікацій (для авторизованих)
- Видалення власних публікацій
- Поділитись посиланням (через native share API)

### UX
- Toast-сповіщення для всіх дій
- Адаптивна верстка (mobile first)
- Валідація форм з повідомленнями
- Показ/приховування пароля
- Перегляд карми та статистики у профілі
- Збереження сесії у `localStorage`

## Структура

```
app/
  page.tsx              Головна стрічка
  about/                Про платформу
  auth/                 Вхід
  auth/register/        Реєстрація
  post/[id]/            Деталі публікації
  post/new/             Створення публікації
  profile/              Профіль
  profile/edit/         Редагування профілю
components/             UI компоненти
lib/
  auth.ts               Хешування паролів, валідація
  store.tsx             Стан (React Context + localStorage)
  toast.tsx             Сповіщення
  mockData.ts           Початкові дані
  utils.ts              Утиліти
types/                  TypeScript типи
```

## Стек

Next.js 14, TypeScript, Tailwind CSS, lucide-react, date-fns.

Дані живуть у `localStorage` (хешування паролів через Web Crypto SHA-256). Для бекенду — додайте API роути в `app/api/` та підключіть Supabase/Postgres.
